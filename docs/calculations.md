# CALCULATIONS.md

# FREELY 금융 계산 공식

> 이 문서는 FREELY에서 사용하는 금융 계산의 기준 문서다.

---

# 1. 기본 숫자 규칙

금액:

```text
KRW
```

금리는 내부적으로 소수로 변환한다.

```text
7% = 0.07
```

연간 기간:

```text
1년 = 12개월
```

MVP의 투자 계산은 월 단위 시뮬레이션을 기본으로 한다.

---

# 2. 복리 계산

## 2.1 초기 투자금만 있는 경우

```text
FV = PV × (1 + r)^n
```

FV:

미래 가치

PV:

현재 투자금

r:

연 수익률

n:

투자 기간(년)

---

## 2.2 월 단위 계산

연 수익률을 월 수익률로 변환하여 월 단위 계산을 수행한다.

MVP에서는 계산 방법을 코드와 테스트에서 명확하게 고정한다.

예:

```text
연 수익률 = 7%

월 수익률 = 0.07 / 12
```

---

# 3. 적립식 투자

매월 동일한 금액을 투자한다고 가정한다.

월 투자금:

```text
PMT
```

월 수익률:

```text
r
```

총 투자 개월:

```text
n
```

기본 미래가치:

```text
FV =
PMT × ((1+r)^n - 1) / r
```

초기 투자금이 있는 경우:

```text
FV =
PV × (1+r)^n
+
PMT × ((1+r)^n - 1) / r
```

단, 실제 구현에서는 납입 시점이 월초인지 월말인지 명확하게 정의해야 한다.

MVP에서는 **월말 납입**을 기본 가정으로 한다.

---

# 4. 총 투자원금

```text
총 투자원금 =
초기 투자금 + 월 투자금 × 총 개월 수
```

---

# 5. 투자수익

```text
투자수익 =
최종 자산 - 총 투자원금
```

---

# 6. 배당금

투자자산:

```text
A
```

연 배당수익률:

```text
y
```

연간 배당금:

```text
Annual Dividend = A × y
```

월 평균 배당금:

```text
Monthly Dividend = Annual Dividend / 12
```

주의:

월 평균 배당금은 실제 월별 지급액을 의미하지 않는다.

실제 배당 지급 주기는 금융상품에 따라 다를 수 있다.

---

# 7. FIRE 목표자산

월 생활비:

```text
M
```

연 생활비:

```text
Annual Expense = M × 12
```

목표 인출률:

```text
W
```

FIRE 목표자산:

```text
FIRE Target =
Annual Expense / W
```

예:

```text
월 생활비 = 3,000,000원
연 생활비 = 36,000,000원
인출률 = 4% = 0.04

36,000,000 / 0.04
= 900,000,000원
```

---

# 8. FIRE 달성률

현재 투자 가능 자산:

```text
A
```

FIRE 목표자산:

```text
T
```

```text
Progress = A / T × 100
```

화면에서는 0~100% 범위로 제한한다.

```text
Math.min(Progress, 100)
```

---

# 9. FIRE 예상 시점

매월 다음 순서로 계산한다.

```text
1. 현재 자산에 월 수익률을 적용
2. 월 투자금을 추가
3. 현재 자산이 목표자산 이상인지 확인
4. 목표에 도달하지 않았다면 다음 달 계산
```

개념적으로:

```text
Asset_next =
Asset_current × (1 + monthlyReturn)
+
monthlyInvestment
```

목표:

```text
Asset >= FIRE Target
```

최초로 조건을 만족하는 월을 FIRE 달성 시점으로 사용한다.

---

# 10. FIRE 시뮬레이션 데이터

그래프 표시를 위해 매월 다음 데이터를 생성한다.

```text
{
  month,
  age,
  asset,
  contribution,
  investmentReturn
}
```

예:

```text
[
  {
    month: 1,
    age: 30,
    asset: 213000000,
    contribution: 2000000,
    investmentReturn: 1166666
  }
]
```

실제 값은 계산 함수에서 생성한다.

---

# 11. 대출 — 원리금균등상환

대출 원금:

```text
P
```

월 이자율:

```text
r
```

총 상환 개월:

```text
n
```

월 상환금:

```text
M =
P × r × (1+r)^n
/
((1+r)^n - 1)
```

---

# 12. 대출 — 원금균등상환

매월 동일한 원금을 상환한다.

월 원금:

```text
Monthly Principal =
P / n
```

월 이자:

```text
Monthly Interest =
Remaining Principal × Monthly Rate
```

월 상환금:

```text
Monthly Payment =
Monthly Principal + Monthly Interest
```

시간이 지날수록 월 상환금은 감소한다.

---

# 13. 대출 — 만기일시상환

대출 기간 동안 원금을 상환하지 않고 이자를 납부한다.

월 이자:

```text
Monthly Interest =
P × Annual Rate / 12
```

만기 시 원금을 상환한다.

총 상환금:

```text
Total =
P + Total Interest
```

---

# 14. 예금

예치금:

```text
P
```

연 이자율:

```text
r
```

기간:

```text
t
```

단순 예금 계산:

```text
Interest =
P × r × t
```

세전 만기금:

```text
P + Interest
```

세후 계산은 적용 세율을 별도로 정의한 후 구현한다.

---

# 15. 적금

월 납입금:

```text
PMT
```

납입 기간:

```text
n
```

총 납입금:

```text
Total Contribution =
PMT × n
```

적금 이자는 각 납입금이 실제 예치된 기간을 고려하여 계산한다.

MVP 구현 시 납입 시점과 이자 계산 기준을 명확히 정의하고 테스트한다.

---

# 16. 목표금액 — 필요한 월 투자금

목표 미래가치:

```text
FV
```

초기 투자금:

```text
PV
```

월 수익률:

```text
r
```

개월 수:

```text
n
```

적립식 미래가치 공식을 역산한다.

```text
PMT =
(FV - PV × (1+r)^n)
× r
/
((1+r)^n - 1)
```

목표금액이 현재 자산보다 낮은 경우 별도의 예외 처리가 필요하다.

---

# 17. 계산 예외 처리

모든 계산 함수는 다음 상황을 고려한다.

```text
0원
음수
0개월
음수 기간
잘못된 퍼센트
0% 수익률
현재자산 >= 목표자산
목표자산 <= 0
```

특히 수익률이 0%인 경우 일반 복리 공식에서 0으로 나누는 문제가 발생할 수 있으므로 별도 처리한다.

---

# 18. 계산 정확성 원칙

계산 중간 단계에서는 임의로 반올림하지 않는다.

예:

```text
잘못된 방식

월 수익률을 계산하면서 소수점 2자리로 반올림
 ↓
투자 계산
 ↓
결과
```

권장:

```text
원본 입력
 ↓
전체 계산
 ↓
최종 결과에서만 표시용 반올림
```
