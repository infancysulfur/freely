# FREELY — UX / 화면 설계 문서

> 금융 계산을 쉽게 하고, 계산 결과를 통해 자신의 경제적 자유를 이해할 수 있도록 하는 웹 서비스의 UX 기준 문서

---

# 1. UX 문서의 목적

이 문서는 FREELY의 화면 구성과 사용자 경험을 정의한다.

개발자는 이 문서를 기준으로 화면을 구현한다.

이 문서에서 정의하지 않은 세부적인 UI 구현은 개발자가 판단할 수 있지만, 다음 요소는 임의로 변경하지 않는다.

* 페이지 구조
* 주요 사용자 흐름
* 계산기 입력 → 결과 구조
* FIRE 계산기의 핵심 정보
* 모바일 UX 원칙
* 결과 정보의 우선순위

---

# 2. UX 핵심 원칙

FREELY의 모든 화면은 다음 5가지 원칙을 따른다.

## 2.1 Simple

사용자가 금융 지식이 많지 않아도 사용할 수 있어야 한다.

전문 용어가 필요한 경우 간단한 설명을 함께 제공한다.

---

## 2.2 Result First

사용자가 가장 궁금한 결과가 가장 먼저 보이도록 한다.

예:

```text
잘못된 구조

입력
↓
설명
↓
긴 설명
↓
그래프
↓
결과
```

권장 구조:

```text
입력
↓
핵심 결과
↓
상세 결과
↓
그래프
↓
계산 설명
```

---

## 2.3 Explainable

계산 결과가 어디서 나왔는지 사용자가 이해할 수 있어야 한다.

예:

```text
FIRE 목표자산

9억원

계산 기준

연 생활비 3,600만원
목표 인출률 4%

3,600만원 ÷ 4%
= 9억원
```

---

## 2.4 Trustworthy

금융 서비스이므로 과장된 표현을 사용하지 않는다.

좋은 표현:

> 입력하신 조건을 기준으로 예상 FIRE 시점을 계산했습니다.

피해야 할 표현:

> 47세에 반드시 경제적 자유를 달성할 수 있습니다.

---

## 2.5 Mobile First

FREELY의 계산기는 모바일에서도 쉽게 사용할 수 있어야 한다.

특히 숫자 입력이 많은 화면이므로 모바일 키보드와 입력 편의성을 고려한다.

# 10. 입력 Form UX

## 10.1 입력값은 명확하게 표시한다.

좋지 않은 예:

```text
금액
[              ]
```

좋은 예:

```text
현재 투자자산

[ 100,000,000 ] 원
```

---

# 11. 금액 입력

금액 입력은 사용자에게 다음과 같이 표시한다.

```text
[ 10,000,000 ] 원
```

내부적으로는:

```text
10000000
```

을 사용한다.

---

# 12. 퍼센트 입력

예:

```text
예상 연 수익률

[ 7.0 ] %
```

또는 shadcn/ui의 Input + 별도 단위 표시를 사용한다.

---

# 13. 기간 입력

예:

```text
투자 기간

[ 20 ] 년
```

또는:

```text
[ 240 ] 개월
```

사용자에게 가장 이해하기 쉬운 단위를 우선한다.

---

# 14. 입력 기본값

계산기 사용성을 높이기 위해 합리적인 기본값을 제공할 수 있다.

예:

FIRE 계산기:

```text
월 생활비
3,000,000원

현재 투자자산
100,000,000원

월 투자금
2,000,000원

예상 연 수익률
7%

목표 인출률
4%

현재 나이
30세
```

단, 기본값은 사용자의 실제 상황을 의미하지 않는다는 점을 UI에서 명확히 한다.

---

# 15. 입력 오류

오류는 입력 필드 바로 아래에 표시한다.

예:

```text
예상 수익률

[ -5 ]

수익률은 0% 이상의 값을 입력해주세요.
```

가능하면 사용자가 오류를 발견한 후 입력 위치를 쉽게 찾을 수 있도록 한다.

---

# 16. 계산 버튼

기본 문구:

```text
계산하기
```

FIRE에서는:

```text
내 FIRE 계산하기
```

를 사용할 수 있다.

버튼은 입력 영역의 마지막에 배치한다.

# 17. 결과 UX

```text

남은 자산
700,000,000원

달성률
22.2%
```

# 20. 그래프 UX

그래프를 단순 장식으로 사용하지 않는다.

투자/FIRE 계산기에서는 자산 증가 그래프를 적극적으로 활용한다.

# 21. FIRE 계산기

FIRE 계산기는 FREELY의 대표 기능이다.

URL:

```text
/calculators/fire
```

---

# 22. FIRE 페이지 목표

사용자가 페이지에 들어와 다음 질문에 답을 얻을 수 있어야 한다.

> "나는 경제적 자유를 위해 얼마가 필요한가?"

그리고:

> "현재 상황이라면 언제쯤 가능한가?"

---

# 23. FIRE 입력 구조

입력은 크게 3개 영역으로 구분한다.

```text
① 생활비
② 현재 자산 / 투자
③ 투자 가정
```

---

## 23.1 생활비

```text
월 생활비

[ 3,000,000 ] 원
```

설명:

> 경제적 자유 이후 한 달에 필요한 생활비를 입력하세요.

---

## 23.2 현재 자산 / 투자

```text
현재 투자 가능 자산

[ 200,000,000 ] 원

월 투자금

[ 2,000,000 ] 원

현재 나이

[ 30 ] 세
```

여기서 투자 가능 자산은 사용자가 FIRE 목적에 사용할 수 있다고 판단한 자산을 의미한다.

부동산 등 현금화하기 어려운 자산은 사용자가 직접 판단하도록 안내한다.

---

# 24. 투자 가정

```text
예상 연 수익률

[ 7.0 ] %

목표 인출률

[ 4.0 ] %
```

각 입력값에는 도움말을 제공한다.

예:

```text
목표 인출률 ⓘ

FIRE 이후 자산에서 매년 사용할 비율입니다.
예: 4%를 입력하면 연간 자산의 4%를
생활비로 사용하는 것으로 가정합니다.
```

# 30. FIRE 시뮬레이션

사용자가 자신의 조건을 변경하면서 결과를 비교할 수 있도록 확장한다.

MVP에서는 우선 다음 3가지 변수를 제공한다.

```text
월 투자금
예상 수익률
월 생활비
```

예:

```text
월 투자금을

200만원 → 300만원

으로 변경하면

예상 FIRE 나이

47세 → 44세
```

와 같이 결과 변화를 보여준다.

---

# 31. FIRE 결과 설명

계산 결과 바로 아래에 간단한 설명을 제공한다.

예:

```text
현재 조건에서는 약 9억원의 투자자산이 필요합니다.

현재 투자자산 2억원을 기준으로
매월 200만원을 투자하고 연 7% 수익률을
가정하면 약 47세에 목표자산에 도달합니다.
```

단, "도달합니다"보다는 "도달하는 것으로 계산됩니다"와 같은 표현을 우선한다.

---

# 32. FIRE 계산 기준 표시

결과 화면에는 계산에 사용한 주요 조건을 표시한다.

```text
계산 기준

월 생활비       300만원
현재 자산       2억원
월 투자금       200만원
예상 수익률     7%
인출률          4%
```

사용자가 어떤 조건으로 결과가 계산되었는지 확인할 수 있어야 한다.

---

# 33. FIRE 주의사항

결과 하단에 다음 취지의 안내를 표시한다.

```text
이 계산 결과는 입력한 조건을 기반으로 한
시뮬레이션 결과입니다.

실제 투자수익률, 물가, 세금, 투자상품의 변동성 등에 따라
실제 결과는 달라질 수 있습니다.
```

# 34. 관련 금융상품 영역

MVP에서는 실제 금융상품 데이터를 제공하지 않는다.

향후 다음과 같은 영역을 추가한다.

```text
목표 수익률에 참고할 수 있는 금융상품

예금
적금
ETF
배당주
채권
```

이 영역은 향후 금융 데이터 시스템 구축 후 구현한다.

MVP에서는 UI 자체를 만들지 않는다.

---

# 35. 관련 계산기

모든 계산기 페이지 하단에는 관련 계산기를 표시한다.

예:

복리 계산기:

```text
함께 사용하면 좋은 계산기

→ 목표금액 계산기
→ 배당금 계산기
→ FIRE 계산기
```

FIRE 계산기:

```text
함께 사용하면 좋은 계산기

→ 복리 계산기
→ 투자 목표금액 계산기
→ 배당금 계산기
```

---

# 36. 계산 방법 영역

페이지 하단에는 계산 방법을 제공한다.

예:

```text
FIRE 목표자산 계산 방법

연간 생활비 ÷ 목표 인출률

월 생활비 300만원 × 12
= 연 생활비 3,600만원

3,600만원 ÷ 4%
= 9억원
```

계산 공식은 `docs/CALCULATIONS.md`와 일치해야 한다.

---

# 37. FAQ 영역

SEO와 사용자 이해를 위해 각 계산기 페이지에 FAQ를 제공할 수 있다.

예:

FIRE 계산기:

```text
Q. FIRE란 무엇인가요?

Q. FIRE 목표자산은 어떻게 계산하나요?

Q. 인출률 4%는 무엇인가요?

Q. 수익률을 몇 %로 입력해야 하나요?

Q. 부동산도 FIRE 자산에 포함해야 하나요?
```

MVP에서는 질문과 답변의 범위를 과도하게 확장하지 않는다.

# 45. 색상 원칙


# 46. 강조 색상

결과를 강조할 때는 Primary 색상을 사용한다.

위험 또는 오류는 Destructive를 사용한다.

긍정적인 결과라고 해서 모든 결과를 초록색으로 표시하지 않는다.

# 47. 애니메이션

MVP에서는 애니메이션을 최소화한다.

계산 결과가 나타날 때 간단한 transition 정도만 허용한다.

숫자가 빠르게 올라가는 카운팅 애니메이션은 필수가 아니다.

# 48. 접근성

기본적인 접근성을 준수한다.

* 모든 Input에 Label 제공
* 버튼에 명확한 텍스트 제공
* 색상만으로 상태를 구분하지 않음
* 오류 메시지를 명확하게 표시
* 키보드만으로도 주요 기능 사용 가능
* 충분한 터치 영역 확보

# 53. 최종 UX 원칙`

FREELY의 모든 화면은 다음 질문에 답할 수 있어야 한다.

> 사용자가 지금 무엇을 해야 하는가?

그리고 계산 후에는:

> 그래서 결과가 무엇인가?

마지막으로:

> 이 결과를 어떻게 이해해야 하는가?

이 세 가지가 명확하지 않은 UI는 개선 대상으로 본다.
